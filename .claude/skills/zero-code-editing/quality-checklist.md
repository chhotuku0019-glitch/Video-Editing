# Final Quality Checklist (report PASS/FAIL/NOT CHECKED for each)
- [ ] Aspect ratio correct (16:9 or 9:16)
- [ ] Resolution correct (1920x1080 or 1080x1920)
- [ ] Audio/video sync (spot-check at start, middle, end)
- [ ] Voiceover clarity; no clipping
- [ ] Music below voice; loudness near -14 LUFS, peak ≤ -1 dBTP
- [ ] No repeated SFX (checked against SFX log)
- [ ] Subtitle/text placement inside safe areas; no overcrowding
- [ ] Typography quality (hierarchy, spacing, Devanagari rendering)
- [ ] Visual consistency
- [ ] Color/grade consistency; palette per notes
- [ ] No unnecessary empty scenes
- [ ] No important narration/facts removed (compare with script)
- [ ] File plays, correct duration, ffprobe clean, `faststart`
- [ ] Outputs delivered (MP4, manifest, assets, notes, render script)
If anything failed or could not be verified, say so plainly.
