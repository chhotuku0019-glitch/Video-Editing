# Shorts Workflow (/shorts) — 9:16, 1080x1920
1. Inventory video; transcribe/analyse speech if tools exist; find candidate segments (20–60 s typical; choose by content).
2. If several good segments exist, present 2–4 candidates (time range, hook, why) and ask the user to choose. If one is clearly best, state it and proceed.
3. Hook in the first 1–3 seconds (strong line, striking visual, or bold text). Never open with slow intro.
4. Vertical framing: never blind center-crop. Options: smart crop following subject (tracking), repositioned crop per shot, or blurred/graded designed background with the 16:9 clip in the center plus title/caption blocks. Keep important text and subjects fully visible.
5. Motion graphics relevant to content; typography hierarchy; selective captions only (key words/phrases), inside safe zones.
6. Sound: balanced, voice first, non-repeating SFX.
7. Clean ending: end on a complete thought; optional short end card; loop-friendly if natural. No abrupt cut mid-sentence.
8. Render 1080x1920, H.264 + AAC, ≤ 60 s unless user asks, then QC with `qc_check.sh <file> vertical`.
